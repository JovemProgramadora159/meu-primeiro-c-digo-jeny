# Minha Primeira Variável

Este programa foi criado para testarmos a criação de variáveis.

## O que é uma variável?

uma caixa que guarda uma informação e essa informação poderá ser acessada e utilizada a qualquer momento

## O que faz o Console.Write?

pede ao programa que acesse o console e escreva algo

## Qual é a diferença entre Console.Write e Console.WriteLine?

o primeiro pede ao programa que escreva no console e o outro pede que escreva, enquanto especifica que quer pular linha
